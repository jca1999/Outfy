==================================================
PRODUCT RULES
==================================================

An activity review has:

- rating: 1 to 5 stars
- optional text comment
- one review per user per activity
- user may later edit their own review

A user may review an activity ONLY when:

1. The activity exists.
2. The activity is NOT cancelled.
3. The activity has finished.
4. The user really participated with:

   activity_members.role = 'participant'

5. The user is NOT the activity creator/organizer.

The organizer must NEVER be able to rate their own activity.

==================================================
WHEN IS AN ACTIVITY FINISHED?
==================================================

Use:

ends_at

when ends_at is present.

Otherwise use:

starts_at

Therefore an activity is reviewable when:

coalesce(ends_at, starts_at) <= current time

This is important.

Example:

starts_at = 18:00
ends_at = 20:00

At 19:00:
NOT reviewable yet.

At 20:01:
reviewable.

If no ends_at exists:

starts_at <= now

is sufficient.

Do NOT require status = 'completed', because Outfy currently may still have
past activities whose database status remains 'active'.

However:

status = 'cancelled'

must NOT be reviewable.

==================================================
RPC — RATING VALIDATION
==================================================

If:

p_rating < 1
or
p_rating > 5

return a stable result such as:

invalid_rating

Do not insert/update anything.

==================================================
RPC — COMMENT VALIDATION
==================================================

Trim the supplied comment.

If trimmed comment is empty:

store NULL.

If comment is longer than 1000 characters:

return:

comment_too_long

Do not silently truncate user text.

==================================================
RPC — ACTIVITY LOOKUP
==================================================

Load the activity.

If it does not exist:

return:

not_found

==================================================
RPC — CANCELLED ACTIVITY
==================================================

If activity.status = 'cancelled':

return:

cancelled

Do not allow rating.

==================================================
RPC — ORGANIZER
==================================================

If:

activity.creator_id = p_user_id

return:

organizer_cannot_review

Do not create/update a review.

==================================================
RPC — FINISHED CHECK
==================================================

Calculate activity finish moment as:

coalesce(ends_at, starts_at)

If it is greater than current time:

return:

not_finished

Do not create/update the review.

==================================================
RPC — REAL PARTICIPATION
==================================================

Check:

public.activity_members

for:

activity_id = p_activity_id
user_id = p_user_id
role = 'participant'

If no such row exists:

return:

not_participant

The organizer membership does NOT count.

Do not rely only on creator_id.

==================================================
RPC — UPSERT
==================================================

If all checks pass:

Insert the review if it does not exist.

If the same user already reviewed that activity:

UPDATE their existing:

rating
comment

Do NOT create a second review.

Preserve original created_at.

updated_at should update normally.

Return:

saved
