We are continuing development of Outfy.

The current important state is:

- Users can create and publish REAL activities.
- Activities are stored in public.activities.
- The organizer is automatically inserted into public.activity_members.
- Activity Detail already exists at /activities/:id.
- The Profile screen already exists.
- Authentication uses the existing Outfy server-side session architecture.
- The frontend must NOT access Supabase directly.

CURRENT UX PROBLEM:

A user can publish an activity, but after leaving the success screen there is
currently no normal way inside Outfy to find the activities they created.

We now need the first real "My Activities" feature.

Profile

==================================================

==================================================
SORTING
==================================================

For this first version, sort created activities primarily by:

starts_at ascending

for future/upcoming activities.

If there are already past activities, do NOT hide them yet.

A reasonable overall stable ordering is:

1. active future activities first, nearest date first
2. then remaining activities by starts_at descending

But do NOT build a complex History system in this task.

The important thing is that recently relevant plans are easy to find.
