==================================================
ACTIVITY LOOKUP
==================================================

Load the requested activity from:

public.activities

The server uses the privileged Supabase client and therefore bypasses RLS.

Because of that, authorization MUST be explicitly enforced in server code.

An authenticated user may read:

- an activity with status = 'active'

OR

- their own activity, regardless of status

Do NOT return another user's cancelled/completed activity unless future
rules explicitly allow it.

If the activity does not exist OR the authenticated user is not allowed
to view it, return the existing appropriate not-found style response.

Do not expose whether an inaccessible private/non-active record exists.
