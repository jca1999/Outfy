2. JOIN ENDPOINT
==================================================

Add:

POST /api/activities/:id/join

Authentication required.

The endpoint must:

1. validate the activity ID
2. get current user from the Outfy session
3. NEVER accept userId from request body/query
4. call:

public.join_activity_as_user

with:

p_activity_id = route activity ID
p_user_id = authenticated session user ID

DO NOT directly INSERT into activity_members.

==================================================

==================================================

joined

HTTP 200:

{

  memberCount,
  maxParticipants
}

already_member

HTTP 200:

{
  result: "already_member",
  memberCount,
  maxParticipants
}

full

HTTP 409 with stable safe code:

activity_full

not_active

HTTP 409:

activity_not_active

not_found

HTTP 404.

Unexpected error:

HTTP 500 using existing safe API conventions.

Do NOT expose raw Supabase/Postgres errors.

organizer_cannot_leave

HTTP 404.

PARTICIPANT STATE
==================================================

- call leaveActivity()

maxParticipants -> server returned value when available

Do NOT calculate memberCount - 1 locally.

==================================================
NON-MEMBER STATE
==================================================

If:

membershipRole === null

AND activity is active

AND it has capacity

show a strong primary CTA:

Spanish:
"Unirme al plan"

English:
"Join plan"

On click:

- disable while pending
- prevent duplicate requests
- call joinActivity()
- do NOT optimistically add membership

If response is:

joined

membershipRole -> participant

use returned authoritative memberCount.

If response is:

already_member

reconcile safely:

membershipRole -> participant

use returned authoritative memberCount.
