==================================================
CREATE PLAN PAGE
==================================================

Create:

artifacts/outfy/src/pages/create-activity.tsx

The page must be mobile-first and also work well on desktop.

Use the existing Outfy design language.

Do NOT make it look like a professional event-management form.

Creating a casual plan should feel simple and friendly.

The conceptual question should be:

"What do you want to do?"

==================================================
SECTION 1 — WHAT
==================================================

Include:

TITLE
Required.

Examples conceptually:
- Partido de fútbol
- Ir al cine
- Dar una vuelta
- Ir al concierto

Use local state only.

DESCRIPTION
Optional.

CATEGORY
Required.

Read the available categories from:

activity-taxonomy.ts

Do NOT duplicate the taxonomy manually.

Display category labels through the existing "activities" i18n namespace.

SUBCATEGORY
Required.

After choosing a category, show only that category's subcategories.

Example:

Sports
-> Football
-> Padel
-> Basketball

Social
-> Drinks
-> City walk
-> Meet people

Use translated labels but preserve internal taxonomy IDs.

==================================================
SECTION 2 — WHEN
==================================================

Include:

- date
- start time
- optional end time

Date and start time are required.

End time is optional.

Do not allow obviously invalid local form states such as an end time earlier than the start time when both refer to the same day.

No backend validation is needed yet.

==================================================
SECTION 3 — WHERE
==================================================

Use the existing taxonomy location types:

physical
online

Show a clear selector:

- Presencial / In person
- Online

If ONLINE:

Show a simple optional field such as:

"Platform or place online"

Example:
Discord, PlayStation, Steam, etc.

This is local UI only.

If PHYSICAL:

For this first UI prototype, DO NOT reuse LocationPicker because it represents the user's saved HOME location and must not be modified.

Instead provide simple local-only fields for:

- City
- Meeting point / area

The meeting point should be optional.

Do NOT request GPS.

Do NOT access browser geolocation.

We will build the proper activity location system separately later.

==================================================
SECTION 4 — PEOPLE
==================================================

Allow the organizer to choose:

- limited participants
- no participant limit

If limited:

Show a max participants numeric field.

Minimum:
2

Do not invent a hard maximum unless needed for reasonable input validation.

==================================================

==================================================

Provide these options:

free
paid
each_own

Conceptually:

Spanish:
- Gratis
- Tiene coste
- Cada uno paga lo suyo

English:

- Everyone pays their own

If "paid" is selected:

- currency

For this prototype support at least:

USD
