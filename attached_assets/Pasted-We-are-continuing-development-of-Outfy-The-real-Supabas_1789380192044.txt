==================================================

==================================================

- optional end time

For this first real implementation, use the browser's current IANA

Build valid ISO timestamps from the selected local form date/time.

Send:

to the server.

The server must validate that:

- endsAt, when present, is valid and later than startsAt

Do NOT install a date library.

IMPORTANT:

browser timezone.

Do not attempt to infer the timezone from a manually entered city yet.

==================================================
SERVER VALIDATION
==================================================

Do not rely solely on frontend validation.

Validate the incoming request on the API server before inserting.

Match the LIVE database rules.

TITLE

- required string
- trim it
- 1 to 120 characters

DESCRIPTION

- optional
- maximum 5000 characters

CATEGORY / SUBCATEGORY

- required non-empty strings
- store the stable taxonomy IDs received from the UI
- do not store translated labels

Do NOT duplicate the full taxonomy in the API for this task.

LOCATION TYPE

Allowed:

- physical
- online

PHYSICAL

Requires:
- non-empty city

May contain:
- countryCode
- regionCode
- regionName
- latitude
- longitude
- meetingPoint

ONLINE

May contain:
- onlinePlatform

Do not invent physical coordinates.

If coordinates are supplied:

- both latitude and longitude must exist
- latitude -90..90
- longitude -180..180

If countryCode is supplied:

- normalize/validate as two uppercase letters

PARTICIPATION

Allowed:

- limited
- unlimited

Limited:
- maxParticipants integer >= 2

Unlimited:
- maxParticipants must be stored as null

Remember:
maxParticipants includes the organizer.

COST

Allowed:

- free
- paid
- each_own

Free:
- estimatedCost -> null
- currency -> null

Paid:
- estimatedCost > 0
- currency required
- normalize currency uppercase

Each own:
- estimatedCost and currency may be null

Do not implement payments.
