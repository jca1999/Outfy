==================================================
GOAL 1 — OPEN PICKER FROM THE WHOLE FIELD
==================================================

For the existing Create Plan fields:

- Date
- Start time
- Optional end time

Make clicking/tapping anywhere inside the field open the native browser picker.

Where supported, use:

HTMLInputElement.showPicker()

Do not require the user to click a small browser icon.

Preserve the normal native input fallback for browsers where showPicker()
is not supported.

Do NOT create a custom calendar or clock picker.

==================================================
GOAL 2 — REMOVE CUSTOM DATE/TIME ICONS
==================================================

Remove the custom Calendar and Clock icons currently shown inside these
fields.

They are unnecessary because:

- the entire field will open the native picker
- they have poor visibility in the current dark theme
- they add visual noise

Do not replace them with different custom icons.

If the browser shows its own native date/time affordance, leave normal
browser behavior intact unless the current CSS already hides it safely.

==================================================
GOAL 3 — EMPTY FIELD PLACEHOLDER / FORMAT HINT
==================================================

When no value has been selected yet, the field should visually communicate
the expected format in a subtle muted/gray style.

Date:

Spanish and English:
"dd/mm/aaaa"

Time:

Spanish and English:
"hh:mm"

IMPORTANT:

Native input type="date" and type="time" placeholder support is inconsistent.

Do NOT rely only on the native HTML placeholder attribute if it does not
render reliably.

Implement the smallest robust visual solution compatible with the existing
native inputs.

Requirements:

- Empty date field visually shows "dd/mm/aaaa"
- Empty start-time field visually shows "hh:mm"
- Empty optional end-time field visually shows "hh:mm"
- Once a value is selected, the hint disappears
- The real selected native date/time value remains the actual form value
- Clicking the hint/field still opens the native picker
- Do not replace native date/time inputs with custom text inputs
- Do not break keyboard accessibility
- Do not block mobile native pickers
