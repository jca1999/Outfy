I want to create a social application called Outfy.

Outfy is an app for discovering activities and plans, meeting people with similar interests, and organizing real-life meetups.

The application should initially be built as a responsive, mobile-first web application.

It must work well on:
- desktop browsers
- mobile browsers
- as a PWA in the future
- and it should be prepared to be packaged later as Android and iOS apps using Capacitor.

TECH STACK:
- React
- TypeScript
- modern, maintainable architecture
- reusable components
- mobile-first responsive design

IMPORTANT:
For now, DO NOT implement:
- backend
- database
- authentication
- Supabase
- real chat
- notifications
- maps
- payments
- external services

Use only local mock data.

The goal of this first step is to create the base UI and project architecture.

APP NAME:
Outfy

CORE CONCEPT:
The user opens Outfy because they want to find something to do and people to do it with.

The application should initially have five main sections:

1. Home
2. Explore
3. Matches
4. Chats
5. Profile

On mobile devices, these sections should appear as a bottom navigation bar.

On desktop, adapt the navigation and layout to make good use of the wider screen, while still feeling like a modern application rather than a traditional website.

DESIGN:

I want the design to feel:
- modern
- social
- youthful but professional
- clean
- visual
- friendly
- mobile-first

Do NOT make it look like Tinder or a dating app.

The main focus of Outfy should be plans and activities.

Profiles and matches are secondary social features.

Organize the project cleanly into:
- pages/routes
- components
- types
- constants
- mock-data
- utilities

Prepare the architecture so we can later add:
- Supabase
- authentication
- real activities
- user profiles
- likes
- matches
- real-time chat
- geolocation
- notifications
- Spanish/English internationalization
- Capacitor

Do not implement those features yet.

Prioritize a clean and simple foundation over complexity.
