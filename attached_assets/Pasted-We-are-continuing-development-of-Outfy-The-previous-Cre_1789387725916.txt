clicking/tapping ANYWHERE inside the visible field must open the native

==================================================
IMPLEMENTATION
==================================================

Keep the real native inputs:

input type="date"
input type="time"

Do NOT replace them with text inputs.

Use refs for the three inputs if necessary.

On a direct user click/tap on the field:

1. focus the actual input
2. call input.showPicker() synchronously when supported

Example conceptually:

if (typeof input.showPicker === "function") {
  input.showPicker()
}

Use normal native input behavior as fallback when showPicker() is not
available.

IMPORTANT:

Do not delay showPicker() with setTimeout or async code because browsers may
reject it if it is no longer inside the user gesture.
